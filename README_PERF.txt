ПРОИЗВОДИТЕЛЬНОСТЬ / ПОДДЕРЖКА СЛАБОГО ЖЕЛЕЗА
================================================

Клавиша F1 — Performance / Stability mode
------------------------------------------
Переключает лимит кадров между "до 60fps" (по умолчанию) и жёсткими
стабильными "~30fps" (glfwSwapInterval(2) — GPU простаивает вдвое
больше времени за секунду, ощутимо меньше нагревается).

На ноутбуках со встроенной видеокартой (Intel/AMD iGPU) погоня за
60fps под устойчивой нагрузкой часто приводит к тепловому троттлингу:
чип упирается в температурный лимит через 20-30 секунд и сам снижает
частоты, из-за чего fps начинает скакать (например 60 -> 27-40 и
обратно) — это защита железа, а не баг рендера. План электропитания
Windows тут не помогает (он не может остановить физический нагрев).

Стабильные 30fps почти всегда ощущаются лучше "плавающих" 60, которые
то и дело проседают ниже 30 под троттлингом — поэтому F1 сделан
легко доступным переключателем во время игры, а не настройкой, спрятанной
в конфиге.

Клавиша F3 — замер без vsync
-----------------------------
Отключает vsync (fps не ограничен). Нужна только для замеров: при vsync
встроенная видеокарта сбрасывает частоту, чтобы растянуть работу на весь
кадр, и цифры gpu в строке [perf] завышаются. Без vsync они показывают
реальную стоимость проходов. Повторное нажатие возвращает vsync.

Диагностика в консоли
----------------------
Раз в секунду в консоль печатается:

    [perf] fps = 58.4 (avg frame time 17.12 ms) | gpu scene=4.10 ascii=2.35 crt=0.00 ms | tris=9888 chunks=8 torches=20 particles=162 lens=1 | ram=120.3 MB

  fps / avg frame time — за последнюю секунду по реальным часам.
  gpu scene / ascii    — время GPU на 3D-сцену и на ASCII-конвейер
                          (AcerolaAscii + ascii_post), среднее за секунду.
  gpu crt              — время ЭЛТ-эффекта; 0, когда CRT выключен в
                          настройках. Послесвечение люминофора работает
                          только при выключенных шейдерах.
                          Если fps низкий, а сумма gpu заметно меньше
                          16.7 мс — узкое место не в GPU (CPU, драйвер,
                          vsync, троттлинг).
  tris / chunks        — что прошло куллинг в последнем кадре.
  torches              — активные факелы (лимит MAX_ACTIVE_TORCHES = 20).
                          Тени от стен запечены при загрузке карты
                          (TorchShadowMap), поэтому цена факела — два чтения
                          текстуры на освещённый пиксель.
  particles            — точки-искры факелов.
  lens                 — эффект линзы (1/0).
  ram                  — приватная память процесса (как «Рабочий набор
                          (частный)» в Диспетчере задач).

Замерять лучше в Release-сборке: Debug искажает время CPU.
Для запроса оптимизации присылайте 20-30 строк лога подряд, включая
момент просадки.
